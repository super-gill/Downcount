# Changelog

All notable changes to Downcount are recorded here. Versions follow
[Semantic Versioning](https://semver.org). The game stays on 0.x until a
full first release.

## 0.1.0 - 2026-11-14

First playable version.

### Added

- Letters round with vowel and consonant piles and a list of the longest
  words available.
- Numbers round with a step-by-step calculator, undo, and a solver that
  shows a route to the target.
- Conundrum round with 144 single-answer nine-letter words.
- Quick game (6 rounds), Full game (15 rounds) and single-round practice.
- Thirty-lamp clock with optional tick and time-up sounds.
- Best scores for Quick game and Full game, saved in the browser.
- User guide and technical reference.
